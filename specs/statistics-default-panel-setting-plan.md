# Настройка стартовой панели на странице «Статистика»

## Цель

Дать пользователю возможность выбрать, какая из сворачиваемых панелей страницы
«Статистика» открывается при входе на страницу. Значение хранится только в
`localStorage` текущего браузера: оно не отправляется в API, не попадает в
экспорт и не синхронизируется между устройствами.

Поддерживаемые варианты:

- «Аналитика»;
- «Категории»;
- «Расходы по периодам»;
- «Бюджет»;
- «Не раскрывать панели».

## План

1. В `StatisticsComponent` описать тип идентификаторов панелей и константу
   ключа хранилища, например `statisticsDefaultExpandedPanel`.
2. Добавить безопасные функции чтения и записи настройки в `localStorage`.
   При чтении проверять значение по списку допустимых идентификаторов; пустое,
   повреждённое или устаревшее значение трактовать как «Аналитика».
3. Во время инициализации компонента строить объект `collapsed` из сохранённой
   настройки: выбранная панель получает `false`, все остальные — `true`.
   Для варианта «Не раскрывать панели» все значения будут `true`.
4. Добавить в интерфейс страницы Export отдельный блок настройки, например
   «Стартовая панель статистики», с селектором названий панелей и вариантом
   «Не раскрывать панели». Настройка не отображается на странице Statistics.
5. При изменении селектора на странице Export сразу сохранять новое значение в
   `localStorage`. Если Statistics уже открыта в другой вкладке, новое значение
   начнёт применяться при следующем открытии или обновлении этой страницы.
6. Оставить обычное поведение аккордеона без изменений: клик по панели по-прежнему
   раскрывает только её или сворачивает все, но не меняет сохранённую настройку.
7. Добавить unit-тесты на: значение по умолчанию при пустом `localStorage`,
   восстановление каждого допустимого значения, обработку недопустимого значения,
   режим без раскрытой панели и запись при изменении настройки.
8. Проверить вручную: выбрать каждый вариант на странице Export, обновить
   страницу и открыть Statistics повторно; убедиться, что настройка сохраняется
   только в том же браузерном профиле и не влияет на данные расходов.

## Критерии готовности

- После обновления страницы открывается выбранная пользователем панель.
- При отсутствии настройки, как и сейчас, открыта «Аналитика».
- В `localStorage` хранится только идентификатор панели; Firebase, API и
  экспортируемые данные не изменяются.
- Некорректное значение в `localStorage` не ломает страницу.
